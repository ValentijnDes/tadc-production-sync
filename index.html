Personal production utility

Project files, backed up between workspaces.

TADC Production Sync transfers selected animation project files between the owner's computer, an authorized Dot workspace and the owner's Google Drive.

It uses rclone and local worker scripts to store recovery checkpoints, exchange render jobs and return their results. This site explains that utility; it does not provide public accounts or a download of the owner's project.

Limited Google Drive access

The utility requests https://www.googleapis.com/auth/drive.file. This permits access to specific files created or explicitly opened through this app. It does not request access to Gmail or blanket access to every file in the owner's Drive.

Sign-in and consent take place on Google's own pages. This information site has no sign-in form, file uploader, analytics scripts or access to production credentials.

Personal use

The operator is ValentijnDes. The utility supports a personal, unofficial fan-animation project. It is not affiliated with or endorsed by GLITCH Productions, Gooseworx, Google or OpenAI.

Read the privacy information for storage, access and deletion details, or the terms of use for the utility's scope.

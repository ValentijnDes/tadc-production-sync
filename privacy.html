Privacy information

How project data is used.

Effective 6 November 2026. This policy describes TADC Production Sync, a personal file-transfer and backup utility operated by ValentijnDes.

Access and purpose

The app requests Google's drive.file permission. It reads and writes specific files created or explicitly opened through this app, including project documents, source archives, render-job manifests, outputs and verification records. It also reads available storage quota to avoid exceeding the owner's configured capacity limits.

Google API data is used to carry out the owner's requested file transfers, backup verification, recovery and production-job coordination. It is not sold or used for advertising. Access does not include Gmail or blanket access to unrelated Google Drive files.

Where data is stored

Selected files are stored in the owner's Google Drive and in authorized project directories on the owner's computer and Dot workspace. Google provides the Drive service; OpenAI provides the separately authorized Dot environment. When the owner asks Dot to work with project content, that processing is governed by the owner's OpenAI account settings and applicable service terms.

The transfer utility itself makes no AI API calls. Local credentials and OAuth tokens are stored separately from the public website and production handoff archives. Anyone with access to an authorized workspace may be able to access its local project files; the owner controls access to those workspaces.

Retention and deletion

Backups remain until the owner deletes them. There is no automatic pruning in the current worker. Deleting one copy does not automatically delete copies in other workspaces or archives.

The owner can stop transfers, revoke the app in Google Account's third-party connections settings and remove its local credentials. Revocation prevents further authorized access but does not delete existing backups. To remove retained data, delete the relevant copies from Google Drive, local storage and the Dot workspace, including trash or retained archives where applicable.

This information website

The pages contain no analytics scripts, advertising, cookies set by this site, sign-in form or file uploader. The hosting provider may process ordinary request information, such as IP addresses, under its own privacy practices. No project backups or credentials are published here.

Contact and changes

For questions, use the support address displayed on the Google consent screen, or the operator's GitHub profile. Do not send passwords, tokens or private project files in a public message. This page will be updated if the utility's data practices change.
